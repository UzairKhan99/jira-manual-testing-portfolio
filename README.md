# Jira Manual Testing Portfolio

This repository showcases my practical experience in manual software testing, test case design, and test management using Jira.

## Project 01: Software Testing and Test Management

### Overview
This project documents the design and management of manual test cases for common web application functionalities using Jira.

### Functionalities Covered
- **Login Testing:** Valid and invalid credentials, empty fields, and password validation.
- **Search Testing:** Valid keywords, invalid keywords, empty searches, partial keywords, and letter-case variations.
- **Hotel Booking:** Login and hotel booking scenarios.
- **Shopping Cart:** Adding products to a cart.

### Test Management
- Test case creation and documentation
- Test steps and expected results
- Test cycle organization
- Test execution reporting

### Tools and Technologies
- Jira
- Manual Testing
- Functional Testing
- Test Case Design

### Documentation
The assignment documentation and Jira screenshots are available in the `assignment-01/` folder.

## Learning Outcomes
Practiced organizing test cases, documenting test scenarios, and using Jira to manage software testing activities.
